# 0007. Scoped RBAC

Status: accepted, 2026-11-23

## Context
Roles editable in the DB, scoped to categories.

## Decision
Permissions are declared in code, roles live in the DB. Scopes are pluggable (`register_scope`); taxonomy registers `category` in M1. Endpoints declare permissions per method; the default denies. Nobody can grant, edit or reset beyond their own permissions, or change their own roles. Grants are read per request.

## Alternatives
django-guardian; cached grants.

## Consequences
Revocation is immediate at the cost of one query. A test fails if any endpoint lacks a declaration.
