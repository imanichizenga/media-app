# 0006. Mandatory MFA and step-up

Status: accepted, 2026-11-23

## Context
Every staff account needs MFA; sensitive actions need a fresh check.

## Decision
Passkeys (user verification required) or TOTP; recovery codes. Sessions have stages: `mfa_enroll`, `mfa_challenge`, `active`. Enrolment is refused through a half-open session once any factor exists. Challenges are single use. There is no setting to turn MFA off.

## Alternatives
SMS codes (SIM swap); optional MFA.

## Consequences
Challenge consumption, not the signature counter, prevents replay: synced passkeys always report counter 0.
